聊天室連線（Twitch / YouTube / SOOP）

桌寵不再自己連聊天室——改由獨立的 chat-monitor 負責監聽三個平台並轉發過來。 頻道、API key 等設定都在 chat-monitor 自己的頁面（預設 http://127.0.0.1:3100）設定， 這裡的「模組狀態」分頁只顯示是否連得上它。

先啟動 chat-monitor（node server.js），再啟動桌寵，動畫才會跟著聊天室反應。

OBS Browser Source 設定 官方說明文件 ↗

  1. OBS 左下「來源（Sources）」→ 點 + → 瀏覽器（Browser）
  2. 填入設定：
    • URL：http://localhost:3000
    • 寬度（Width）：1920　高度（Height）：1080
  3. 往下找到 Custom CSS 欄位，貼入以下內容（必填，否則背景會是白色）： 
    body { background-color: rgba(0, 0, 0, 0); margin: 0px auto; overflow: hidden; }
  4. 點 OK 完成，角色即出現在畫面上
  5. 右鍵 Source → Interact 可操作 HUD 按鈕、拖曳角色位置
角色大小：在「桌寵設定」頁調整顯示比例（預設 2，範圍 1–4）。也可以直接在 OBS 中縮放 Source（右鍵 → Transform → Edit Transform）。
Custom CSS 說明：OBS Browser Source 預設背景是白色。貼上這段 CSS 後，rgba(0,0,0,0) 讓背景完全透明，角色才能正確疊在畫面上。若角色周圍出現白框，請確認此欄位有正確填入。

config.json 設定

  • modes：obs（OBS 伺服器）/ test（啟動時開啟測試頁）
  • interactions：互動規則（關鍵詞／指令，也可在「桌寵設定」頁編輯；門檻類規則目前面板不開放編輯，見下方說明）
  • greetingAnimations：觸發揮手動畫的變體與權重
頻道/API key 等聊天室連線設定不在這裡，去 chat-monitor 的頁面設定。修改 config.json 後需重新啟動程式才會生效

互動設定

觀眾打出「關鍵詞」（句子任何地方出現就算）或「指令」（訊息開頭要打對）→ 播放對應動畫，「回應」欄位選填，填了就會在對話泡泡顯示。一組觸發文字可以逗號分隔多個，都對應同一個動作。
