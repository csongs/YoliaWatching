Twitch OAuth Token

  1. 前往 twitchtokengenerator.com
  2. 選擇 Bot Chat Token
  3. 授權後複製 ACCESS TOKEN
  4. 在「設定」頁將 token 填入 TWITCH_OAUTH，格式為 oauth:你的token
測試方式（不需要真的開播）：OBS Stream Key 最後加上 ?bandwidthtest=true，或勾選「啟用頻寬測試模式」

YouTube Data API

  1. 前往 Google Cloud Console
  2. 建立專案 → 啟用 YouTube Data API v3
  3. 建立憑證 → API 金鑰
  4. 在「設定」頁填入 YOUTUBE_API_KEY
每日 10,000 quota 限制，直播中約 500–2,000 quota／小時
配額錯誤提示
  1. 登入 Google Cloud Console，選擇包含 YouTube Data API 的專案。
  2. 點選左上角選單，前往 IAM 與管理 → 配額與系統限制，或從 API 和服務 → 儀表板 找到 YouTube Data API v3。
  3. 在配額頁面檢查每日與每分鐘使用量，若已達上限請等候隔日重置或申請提高配額。
若面板顯示「已超過 YouTube API 配額」，程式會停止重新連線，請先確認 quota 是否已恢復再重新啟動。

OBS Browser Source 設定 官方說明文件 ↗

  1. OBS 左下「來源（Sources）」→ 點 + → 瀏覽器（Browser）
  2. 填入設定：
    • URL：http://localhost:3000
    • 寬度（Width）：1920　高度（Height）：1080
  3. 往下找到 Custom CSS 欄位，貼入以下內容（必填，否則背景會是白色）： 
    body { background-color: rgba(0, 0, 0, 0); margin: 0px auto; overflow: hidden; }
  4. 點 OK 完成，角色即出現在畫面上
  5. 右鍵 Source → Interact 可操作 HUD 按鈕、拖曳角色位置
角色大小：在 config.json 的 obs.scale 調整（預設 2，範圍 1–4）。也可以直接在 OBS 中縮放 Source（右鍵 → Transform → Edit Transform）。
Custom CSS 說明：OBS Browser Source 預設背景是白色。貼上這段 CSS 後，rgba(0,0,0,0) 讓背景完全透明，角色才能正確疊在畫面上。若角色周圍出現白框，請確認此欄位有正確填入。

config.json 設定

  • modes：obs（OBS 伺服器）/ test（啟動時開啟測試頁）
  • twitch.channel：你的 Twitch 頻道 ID
  • youtube.channel：你的 YouTube 頻道 handle，例如 @altheayolia
  • commands：聊天室指令，可自訂 state 和 yolia_see 增減
  • greetings：觸發揮手動畫的關鍵詞列表
修改 config.json 後需重新啟動程式才會生效
