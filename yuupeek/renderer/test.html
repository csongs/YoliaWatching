新增指令

編輯 commands.json，加一行：

// 觸發動畫（播完自動回原狀）：
"!指令": { "state": "動畫名", "yuushi": 0 }

// 同時改幽視值：
"!指令": { "state": "cheer", "yuushi": 10 }

// 只改幽視值（不換動畫）：
"!指令": { "yuushi": -5 }

重新整理此頁即可看到新指令。

新增角色動畫

1. 放入圖片（PNG，從 00 開始）：

assets/sprites/frames/
  └── 動作名稱/
        ├── 00.png
        ├── 01.png
        └── 02.png

2. 在 renderer/character.js 的 ANIMATIONS 加一行：

動作名稱: {
  srcs: frames('動作名稱', 3), // 張數
  loop: true,   // false=播完回原狀
  ms: 150,      // 每幀毫秒（可省略）
},

3. 在 commands.json 新增對應指令即完成。

可用動畫狀態

狀態名說明loop角色位置
